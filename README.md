# GazeAgency

**Utilising Dynamic AOI tracking and Machine Learning for Investigating Learner Agency in AI-Mediated Online Learning Environments**

Project site: https://li-huiyong.github.io/GazeAgency/

GazeAgency is a joint research project between Kyushu University and the Indian Institute of Technology Bombay. It explores how learners direct their attention and make choices in AI-supported online learning.

**Funding.** JST LOTUS Programme.

**Period.** 2026-10-01 – 2027-09-30

日本語: 動的AOI追跡と機械学習を用いたAI媒介型オンライン学習環境における学習者エージェンシーの解明（JST インド若手科学頭脳循環プログラム）
